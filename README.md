# 주유소찾기

가는 길에서 진짜 이득인 주유소 한 곳만 알려주는 사이트.
최저가 목록을 늘어놓는 대신, **돌아갈 가치가 있는지까지 계산해서 없으면 그냥 넣으라고** 말합니다.

전국 주유소 약 1만 곳의 실제 판매가를 매일 받아, 정적 페이지 240여 장을 다시 만듭니다.

## 매일 하는 일

```bash
python scripts/build_all.py
```

이 한 줄이 전부입니다.

1. **수집** — 오피넷에서 오늘 가격 CSV를 받습니다. 다운로드 창구 앞에 NetFunnel(번호표 대기열)이
   있어서 폼만 POST 하면 막히므로, 진짜 브라우저를 띄워 사람이 하듯 내려받습니다.
2. **적재** — CSV를 `oil.db`에 넣고 국면(상승·하락·횡보)을 판정합니다.
3. **점검** — 리포트 본문이 전제하는 주장이 아직 참인지 확인합니다. 깨지면 경고합니다.
4. **생성** — 240여 페이지를 다시 만듭니다.

## 구조

| 경로 | 내용 |
|---|---|
| `/` | 홈 |
| `/area/` | 시군구 227곳 — 우리 동네는 주유소를 고를 가치가 있는가 |
| `/data/` | 리포트 — 요일 속설·브랜드·셀프 차이를 실측으로 검증 |
| `/calc/` | 계산기 — 연간 주유비, 경차 환급, 우회 손익분기 |
| `/policy/` | 지원금·제도 — 유류세 인하 종료, 경차 환급 |

## 스크립트

| 파일 | 역할 |
|---|---|
| `build_all.py` | 위 네 단계를 한 번에 |
| `collect_prices.py` | 오피넷 수집 (Playwright) |
| `load_prices.py` | CSV → DB |
| `figures.py` | **페이지가 인용하는 모든 숫자를 DB에서 계산** |
| `route_gain.py` | 1순위 엔진 — 회랑 4km, 순이득, 500원 문턱 |
| `verdict.py` | 2순위 엔진 — 동네 판정 + 1년 성격 |
| `fill_amount.py` | 얼마나 넣을까 — 국면·제도한도·탱크 |
| `ui.py` | 공통 껍데기 (내비·광고·레이아웃) |

## 설계 원칙

- **숫자를 코드에 박지 않는다.** 기준일도 계산기 기준값도 리포트 본문 수치도 전부 `figures.py`가
  DB에서 계산합니다. 데이터가 갱신되면 글도 따라 바뀝니다.
- **자동 갱신이 거짓말이 되지 않게 한다.** 숫자만 갈아끼우면 "요일 차이는 의미 없다" 같은 주장이
  데이터가 변했을 때 틀린 말이 됩니다. `figures.check_claims()`가 매 빌드마다 확인합니다.
- **지도 SDK를 쓰지 않는다.** 경로 도식은 좌표를 직접 SVG로 그립니다. 비용 0원.
- **표준 라이브러리 위주.** 수집(Playwright)을 빼면 외부 의존성이 없습니다.

## 데이터

출처는 오피넷(한국석유공사)입니다. 원본 파일(`back_data/`, `current_data/`)과 `oil.db`는
용량과 갱신 주기 때문에 저장소에 넣지 않습니다.
